# SQL Injection Prevention Lab — Frontend

React + Vite cybersecurity dashboard interface for the SQL Injection Prevention educational laboratory.

## Tech Stack & Features

- **React 18**: UI component tree and state management
- **Vite**: Rapid local bundling and dev server
- **Lucide Icons**: Cybersecurity icon set
- **CSS3 Dark Cybersecurity Theme**: Glowing status indicators, glassmorphism cards, responsive navigation

## Installation & Running Locally

1. Install npm packages:
```bash
npm install
```

2. Start local Vite development server:
```bash
npm run dev
```

3. Open browser at:
`http://localhost:5173`
