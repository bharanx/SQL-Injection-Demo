SQL Injection — Secure Coding Demonstration

SIIT Academic Security Training Module

1. What is SQL Injection?

SQL Injection (SQLi) is a critical vulnerability that occurs when an application improperly includes untrusted data in a database query. By inserting malicious SQL syntax into an input field (like a search box), an attacker can manipulate the query structure to bypass authentication, expose hidden data, or even destroy the database.

2. What is wrong with the vulnerable code?

The vulnerable application constructs a SQL query by directly embedding the user's search string via formatting/concatenation. The database engine cannot distinguish between the developer's intended SQL commands and the user's input, treating the injected payload as executable code.

Raw SQL + User Input directly incorporated → Executed by Database

If a user types a%' OR '1'='1, the query becomes:
SELECT * FROM students WHERE name LIKE '%a%' OR '1'='1%'
This forces the database to evaluate 1=1 (which is always true), returning all records and bypassing the intended search logic.

3. Secure Coding Modification

The secure version utilizes SQLAlchemy ORM (Object-Relational Mapping). ORMs and parameterized queries separate the query structure from the user data.

Validated Input → Parameterized ORM Query → Executed by Database

When the database executes the parameterized query, the input is strictly treated as a literal string value. Even if the user inputs ' OR '1'='1, the database simply searches for a student whose literal name contains those exact characters, rendering the injection harmless.

4. Before vs After Comparison

BEFORE: Vulnerable Code

@router.get("/students", response_model=List[StudentProfile])
def list_students(q: Optional[str] = None, db: Session = Depends(get_db)):
    query = db.query(Student)
    if q:
        # ❌ VULNERABLE: Direct string interpolation bypasses ORM
        from sqlalchemy import text
        raw_sql = f"(students.name LIKE '%{q}%' OR students.register_number LIKE '%{q}%')"
        
        # EXECUTES MALICIOUS PAYLOAD
        query = query.filter(text(raw_sql))
    
    return query.all()

AFTER: Prevented Code

@router.get("/students", response_model=List[StudentProfile])
def list_students(q: Optional[str] = None, db: Session = Depends(get_db)):
    query = db.query(Student)
    if q:
        # ✅ SECURE: ORM Parameterization
        query = query.filter(or_(
            Student.name.ilike(f"%{q}%"),
            Student.register_number.ilike(f"%{q}%")
        ))
    
    return query.all()
